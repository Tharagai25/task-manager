# Task Manager App

A simple and responsive Task Manager application built using React.js. Organize your daily tasks, track your progress, and stay productive.

## 🚀 Live Demo

**Live Website:** https://task-manager-gjxm.onrender.com

## 📌 GitHub Repository

https://github.com/Tharagai25/task-manager

## ✨ Features

- ➕ Add new tasks
- ✅ Mark tasks as completed or pending
- 🗑️ Delete tasks
- 🔍 Filter tasks by All, Pending, and Completed
- 📊 View total, pending, and completed task counts
- 💾 Save tasks using browser Local Storage
- 📱 Responsive user interface for desktop and mobile devices

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
